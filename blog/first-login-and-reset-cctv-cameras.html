First Login and Reset: What Happens the First Time You Power Up a Camera

New cameras and recorders from the main brands no longer have a known default password. At first use the device asks you to create the admin password. This guide says what each brand does and links to the manufacturers' own pages for the exact steps.

By Ali Zafar · Last updated: November 2026

GaugeCalc does not show, store or guess any password and gives no way around one. Only a factory login that a manufacturer publishes itself is shown, with its official page, and a value is copied here only when the page could be read. Change a factory password at first login and never leave it in use.

Why this matters on site

Knowing that a new device has no default password saves time, and a password you set yourself, not a known default, is the first step of a secure system. Rules can change with new firmware, so the manufacturer's page for your model always wins.

Hikvision

A new device stays inactive until you activate it and create the admin password, in SADP, the web interface, the local menu or iVMS-4200. The password needs at least 8 characters from 3 or more types: digits, upper case, lower case and special characters.

  • Hikvision: device activation with iVMS-4200 (PDF)
  • Hikvision: factory hardening practices (PDF)
  • Hikvision: camera password strategy, activation from firmware 5.3.0 (PDF)

Dahua

Since Dahua's 2017 notice, a new device asks for an admin password, and a reset e-mail address, the first time it starts. Follow the notice for the rules and for resetting a lost password; older firmware can differ.

  • Dahua: initialization and password reset, network cameras
  • Dahua: initialization and password reset, storage devices

Axis

Axis cameras have no default root password. The first time you open the camera in a browser it asks you to set one. Axis advises setting it over an encrypted HTTPS connection, because a first password can travel in clear text. A lost password means resetting the camera to factory settings.

  • Axis: product manuals and help

Reolink

Reolink publishes a factory login for its cameras and recorders. The setup wizard then asks you to create your own password.

  • Reolink: default user and password (official support page)

Other brands

For other brands use the manual of the exact model on the manufacturer's website. Older models may have a factory password printed in the manual or on a label. Never leave a default password on a live system.

Worked example

A new Hikvision recorder shows as inactive in SADP. You activate it, create an admin password of at least 8 characters with 3 kinds of characters, and only then add the cameras.

Limits of this guide

Only brands whose rules were checked against the manufacturer's own documents are listed. The rules can change with new firmware. The Dahua length rule is not quoted because the notices were not clear enough to quote safely.

Frequently asked questions

Do new cameras have a default password?

Not on the main brands covered here. Hikvision (from firmware 5.3.0), Dahua and Axis ask you to create the admin password at first start. Reolink publishes a factory login and its setup wizard then asks for a new password.

What password rules does Hikvision use?

At least 8 characters from 3 or more types: digits, upper case, lower case and special characters.

What do I do if I lose the admin password?

Follow the manufacturer's own reset page for your model. Dahua and Axis publish theirs, linked above. A factory reset on most devices erases settings.

Why does Axis advise HTTPS for the first login?

Because the first password can travel in clear text if the connection is not encrypted.

Where do I find a brand that is not listed?

In the manual of the exact model on the manufacturer's website.
