IPv6 address

What it is: the address you want to look at, as eight groups of hex digits. How to choose: type it as written on the device; the :: shortening and upper or lower case both work. A zone id such as %eth0 and an IPv4 ending are not accepted. Example: 2001:db8::1.

What it is: how many leading bits name the network; the rest name the device (0 to 128 bits). How to choose: use 64 for a normal LAN segment, 128 for one address; a provider often gives a site a shorter prefix such as 48 or 56. Example: 64.

How the IPv6 subnet maths works

An IPv6 address is 128 bits long, written as eight groups of four hex digits. The prefix length says how many bits from the left are the network. The calculator keeps the address as one exact 128-bit integer, so there is no rounding. The network is the address with all device bits set to 0, the last address has all device bits set to 1, and the number of addresses is 2(128 − prefix).

The shortest form of an address

RFC 5952 sets one way to write an address in its shortest form: lower case, no leading zeros in a group, and the longest run of two or more all-zero groups replaced by :: (the first run if two are equal). A single zero group is left as 0. So 2001:0db8:85a3:0000:0000:8a2e:0370:7334 becomes 2001:db8:85a3::8a2e:370:7334.

Worked example

The address 2001:db8:85a3:1234:5678:9abc:def0:1234 with prefix 64 has the network 2001:db8:85a3:1234::/64 and the last address 2001:db8:85a3:1234:ffff:ffff:ffff:ffff. It sits in the documentation block, so the calculator labels it as an example address.

Common mistakes

  • Splitting a LAN below /64. Many features, such as stateless address autoconfiguration, expect a /64.
  • Typing a zone id (fe80::1%eth0) or an IPv4 ending (::ffff:192.0.2.1). Write the last 32 bits as two hex groups instead.
  • Counting hosts like in IPv4. There is no network or broadcast address to subtract in IPv6.

Frequently asked questions

What does the prefix length mean in IPv6?

It is the number of leading bits that identify the network. The remaining bits identify the device inside that network. A /64 leaves 64 bits for devices.

Why is a /64 the normal subnet size?

Standard IPv6 interface identifiers are 64 bits long, and features such as stateless address autoconfiguration expect a 64-bit device part. Smaller LAN subnets can break them.

How do I shorten an IPv6 address?

Drop leading zeros in each group, then replace the longest run of two or more all-zero groups with a double colon. A double colon can be used only once in an address.

Does IPv6 have a broadcast address?

No. IPv6 uses multicast instead of broadcast, so there is no broadcast address to subtract from the subnet size.

Are my addresses sent anywhere?

No. The calculation runs entirely in your browser. Nothing you type is sent to GaugeCalc or anyone else.
