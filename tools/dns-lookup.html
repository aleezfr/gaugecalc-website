DNS Lookup

Type a domain name and choose a record type. The lookup runs in your browser through DNS over HTTPS, so there is nothing to install. Use it to check where a camera cloud name points, whether a mail domain has MX records, or what a domain's name servers are.

Domain

What it is: the name you want to look up, such as a domain or a camera's cloud address. How to choose: type letters, digits and hyphens with at least one dot; no http:// and no path. Example: example.com.
What it is: which kind of record to ask for. How to choose: A and AAAA give the address, MX the mail servers, NS the servers that hold the zone, TXT text such as SPF, CNAME an alias to another name. Example: A.

Privacy: the name you type is sent over HTTPS to Cloudflare's public DNS (cloudflare-dns.com) and, only if that does not answer, to Google Public DNS (dns.google). GaugeCalc does not receive or store it. The lookup runs only when you press Calculate.

Answer

—

A public resolver answers from its cache, so a very recent change may not show yet. This is DNS only: it does not test whether a host is reachable.

What the record types mean

TypeWhat it returns
AThe IPv4 address of a name
AAAAThe IPv6 address of a name
MXThe mail servers of a domain, each with a priority number (lower is tried first)
NSThe name servers that hold the domain's records
TXTText records, for example SPF and domain verification
CNAMEAn alias that points one name to another

How this lookup works

The page sends a DNS over HTTPS (DoH) request from your browser to a public resolver and shows the answer. It tries Cloudflare first and Google Public DNS only if Cloudflare cannot be reached. The result names the resolver that answered. There is no GaugeCalc server in the path, no account and no API key.

Why a camera's cloud name matters

Cameras and recorders that use a cloud name or an NTP server need working DNS. If a device cannot reach its server, a lookup of the same name from another network shows whether the name itself resolves.

Common mistakes

  • Typing a full address such as https://example.com/page. Enter only the name.
  • Looking up a name that has only a CNAME and expecting TXT or MX on it.
  • Reading an empty answer as "the domain does not exist". The status line tells the two apart.

Frequently asked questions

Which servers receive the name I type?

Cloudflare's public DNS (cloudflare-dns.com) and, only if that fails, Google Public DNS (dns.google). GaugeCalc itself does not receive or store the name.

Why is there no WHOIS here?

WHOIS needs a direct TCP connection to port 43, which a web page cannot open. The GaugeCalc mobile app has it.

Why is there no ping or port test?

A browser cannot open raw TCP or UDP connections or scan your local network. Those tools are in the GaugeCalc app.

Why does my lookup show an old address?

Public resolvers cache answers for the time to live (TTL) shown beside each record. A recent change can take that long to appear.

Does it work for internal names?

No. It asks public resolvers, so it only sees public DNS names.
